# v1.1.0 milestone

## Plan

Branch: `v1.1.0`. One PR, squash merge, then tag v1.1.0. No Claude/AI mentions in commits or PR.

### A. Bus scanning + secondary addressing (files: scan.go, scan_test.go, additions to commands.go, gombus.go)
- `(*Client).ScanPrimary(ctx, from, to uint8) ([]uint8, error)`: SND_NKE + REQ_UD2 per address, collect responders, timeout per address is non-fatal.
- Select by secondary address: SND_UD to 0xFD with CI 0x52, 8-byte payload: BCD id (4, wildcards 0xF per nibble), manufacturer (2, 0xFFFF wildcard), version (0xFF), medium (0xFF). Expect E5.
- `(*Client).ScanSecondary(ctx) ([]SecondaryAddress, error)`: libmbus-style wildcard search, digit-by-digit recursion over the 8 BCD id digits; single ACK -> read the meter's header for full address; collision (garbage/multiple) -> recurse deeper.
- `(*Client).ReadBySecondary(ctx, sec) (*DecodedFrame, error)`: select, then ReadSingleFrame at 0xFD.
- Table-driven tests against an in-memory Conn fake.

### B. Fixed data response, CI=0x73 (files: decode_fixed.go, decode_fixed_test.go, small dispatch change in decode.go)
- EN 13757-3 fixed data structure: id (4 BCD), access nr, status, medium/unit bytes, two counters (BCD or binary per status bit 0). Decode into DecodedFrame with two DecodedDataRecords so the existing query API works on it.
- Keep ErrUnsupportedCI for genuinely unknown CI.

### C. Wireless M-Bus decode-only package (files: wmbus/*.go, new package, touches nothing outside)
- Link layer: frame format A and format B, CRC-16 poly 0x3D65 verification (per-block in A, whole-frame in B). Input: raw frame bytes as delivered by a receiver dongle, first byte L-field.
- TPL: CI 0x72 (long), 0x7A (short), 0x78 (none). Encryption modes 0, 5 (AES-128-CBC, IV from mfr/id/ver/medium/access nr), 7 (AES-128-CBC, zero IV, key derived per OMS via AES-CMAC). 2F 2F filler stripping and validation.
- Reuse parent package's record decoding for the application payload (export or reimplement minimal DIF/VIF walk by calling into gombus).
- Tests: real captured wM-Bus telegrams if the model knows published ones (OMS Annex N vectors), plus synthetic round-trip tests (encrypt in the test with the same primitives, then decode).

### D. mbusctl CLI (files: cmd/mbusctl/*) — after A/B
- Subcommands: scan (primary + secondary), read (by primary or secondary address), set-address. `-json` output (records with type, function, storage, tariff, device, value, unit, timestamps). Works over TCP and serial.

### E. Docs (files: example_test.go, README.md, CHANGELOG.md) — after A/B/C
